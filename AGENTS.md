# Публикация результатов

Для замеров через внутренний шлюз используй публичное название **OpenRouter** в лидерборде, на GitHub Pages и в сообщениях о результатах. В публичном JSON записывай это название в поле `provider_label`. Технические сведения о маршруте храни в локальном протоколе прогона.

В лидерборде показывай место, модель и общую оценку из 100. Подробные баллы по заданиям и режимам храни в локальном отчёте.
