# AD&DBench · маршруты

Отдельная серия из четырёх независимых взвешенных карт на seed. На каждой карте показаны все проходы и их стоимость; требуется первый выход единственного маршрута минимальной суммарной стоимости. Состояния и ответы совпадают с четырьмя маршрутными задачами `fixed-probes-0.3-lite.2` AD&DBench для того же seed. Этот раннер использует файловый интерфейс харнеса, поэтому его результаты не считаются автоматически идентичными прежним запросам Chat Completions.

## Запуск

Python 3.12+; дополнительных пакетов задача не требует. Вызов из корня репозитория, например с Claude Code:

```sh
uv run python -m spatial_harness_bench.adnd_route \
  --output runs/adnd-route-example -- \
  claude -p --bare --no-session-persistence --strict-mcp-config \
  --tools Read,Write --allowedTools Read,Write
```

Раннер передаёт условие через UTF-8 stdin в новую сессию на каждом вопросе. Команда харнеса должна прочитать условие и записать `answer.json` в текущей рабочей папке: ровно объект с двумя строковыми полями `id` и `answer`. Неправильный, отсутствующий или некорректный ответ оценивается в 0. Адаптер не должен переносить историю или заметки между вопросами.

По умолчанию используется свежий случайный seed, который записывается локально в `seed.txt`. Для сравнения используйте один и тот же **приватный** seed; для отладки можно указать `--seed 123`, а для закрытого набора предпочтителен `--seed-file /private/seed.txt`, чтобы seed не находился в аргументах процесса. В открытом доступе он становится непригодным для закрытой оценки.

`result.json` содержит `task`, версию, `status`, `score`, `max_score`, `items`, SHA-256 публичного набора и генератора. Для каждой задачи отдельно указаны валидность формата и правильность. Если ответ модели неверен, `points` равен 0; при отказе шлюза, харнеса или чтения файла ставится `status: error`, `points: null`, а оценка всей серии `score: null`. Шлюз использует общую политику повторов проекта. Ошибки не считаются поражениями.

Seed, выданные условия, сданные ответы и результаты хранятся только в локальном каталоге: его новые директории имеют права 0700, файлы — 0600. Не публикуйте этот каталог как есть: условия, ответы модели и seed раскрывают оценочный набор. Изолированная рабочая папка **не является песочницей**: при использовании shell дополнительно ограничьте файловую систему и сеть харнеса, чтобы он не видел исходники, seed и другие прогоны.

Один seed даёт четыре отдельных карты, но направления и ранги стоимости сбалансированы внутри группы. Не считайте вопросы четырьмя независимыми мирами для доверительных интервалов. Для сравнения моделей фиксируйте одинаковые seed, версию, харнес, модель, настройки генерации и бюджет, используйте несколько независимых seed и анализируйте результаты с группировкой по seed. В общем лидерборде Spatial Harness Bench каждая из четырёх карт даёт 1 балл.
